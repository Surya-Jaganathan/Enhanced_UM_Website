# Deployment checklist

- [ ] Upload all files in this package to the root of `Surya-Jaganathan/Enhanced_UM_Website`.
- [ ] Confirm `content/docshub.json` is included in the repository.
- [ ] Commit to the branch configured for GitHub Pages (default: `main`).
- [ ] Open the customer page and confirm manuals, FAQs, and Quick Links render.
- [ ] Open `/admin.html`, sign in with the demo gate, then open **GitHub settings**.
- [ ] Create a fine-grained token restricted to this repository with **Contents: Read and write**.
- [ ] Connect and load the JSON from GitHub before editing content.
- [ ] Add a test FAQ or Quick Link and confirm GitHub shows a new commit to `content/docshub.json`.
- [ ] Wait for GitHub Pages to update, then refresh the customer page from another browser/device.
- [ ] Click **Forget token** when done administering.
- [ ] Do not publish confidential/internal documentation in the public site/repository.
